AI Experience Lab — VS Code 快速啟動
====================================

1. 安裝 Node.js 22.12+（建議 Node.js 22 LTS）
2. 用 VS Code 開啟 ai-experience-lab 資料夾
3. 開啟 Terminal
4. 執行：

   npm install

5. 安裝完成後執行：

   npm run dev

6. 瀏覽器打開終端顯示的 Local URL，例如：

   http://localhost:5173/

正式建置：
   npm run build

注意：三個 AI 模型第一次使用時都需要網路下載預訓練權重。
